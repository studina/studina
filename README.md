## Correr el frontend

Requiere Node.js instalado.

```bash
npm install
npm run dev
```

Abre [http://localhost:5173](http://localhost:5173) en el navegador.

## Correr Directus

Levantar con

```bash
docker compose up -d
```

Abre [http://localhost:8055](http://localhost:8055) en el navegador.
